متجر مستحضرات التجميل — لمسة جمال
===================================

طريقة التشغيل:
1. فك ضغط ملف cosmetics-store.zip في مجلد على الكمبيوتر.
2. افتح VS Code.
3. من File > Open Folder اختَر مجلد cosmetics-store.
4. افتح index.html وشغّله في المتصفح. يُفضّل تثبيت إضافة Live Server في VS Code ثم الضغط بزر الماوس الأيمن على index.html واختيار Open with Live Server.

مهم قبل استقبال الطلبات:
1. افتح script.js.
2. في أول الملف غيّر STORE_NAME إلى اسم متجرك.
3. غيّر WHATSAPP_NUMBER إلى رقم واتساب المتجر بصيغة دولية، أرقام فقط وبدون + أو مسافات.
   مثال مصري: 201XXXXXXXXX
4. عدّل أسماء المنتجات والأسعار والصور داخل مصفوفة products في script.js.

ملاحظات:
- المنتجات والأسعار الحالية أمثلة قابلة للتعديل.
- صور المنتجات يتم تحميلها من الإنترنت، لذلك يلزم اتصال بالإنترنت لعرضها.
- سلة المشتريات محفوظة على نفس المتصفح باستخدام localStorage.
- الطلب لا يُرسل تلقائيًا إلى صاحب المتجر؛ يفتح واتساب برسالة جاهزة، ويجب على العميل الضغط على إرسال.
- هذا المشروع لا يتضمن دفعًا إلكترونيًا أو لوحة تحكم لإدارة المخزون.
- قبل البيع، تأكد من دقة أسماء المنتجات والأسعار ومصدر الصور وحقوق استخدامها.
